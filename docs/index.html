What surfaces

four depths of the same water — every label says what was actually checked
Clear sight
what the code confirms, and how it was seen
✓ defineda definition node exists (treesitter)
✓ referenced (text)the token occurs in the concern's files (ripgrep)
✓ no matches (rg)the prohibition found nothing
✓ passing (ran 4m ago)that spec exited 0, nothing moved since
Foresight
the glass also shows what is not yet
✗ absentdescribed, not yet real

This is the verdict you write on purpose. State the change as a claim; it surfaces absent; that is your worklist in the same vocabulary as everything already true. :ScryCascade makes it so.

Omens
warnings, each carrying its evidence
✗ VIOLATEDa prohibition matched — with the line that proves it
✗ FAILINGa spec exited non-zero — with its output
✗ unreferencedthe target exists; this concern never touches it

A violated prohibition is proof. A clean one is only evidence — no textual match is not absence of behaviour.

Murk
what the glass admits it cannot see — never a pass
– uncheckedno resolver for this language
– unrunnobody has run that spec
– staleit passed, but the code has moved since
– vacuous?it passes while nothing it covers exists yet

Foresight to fact

the whole workflow is one buffer and three commands
name it
Write the claim for the thing you want.
It surfaces ✗ absent. If you can't state it as a claim, you don't know what you're asking for yet — the glass just told you that for free.
summon the proof first
Cascade the exercises claim before the code.
The spec is conjured, you read it, and :ScryRun must come back red. A check that passes before the feature exists asserts nothing.
make it so
Cascade the contains claim.
conjurer casts it with the concern as context — and with this concern's never rules and spec paths withheld. A rule the generator never saw, checked after, is evidence. One it was shown is obedience.
sign what you saw
:ScryRun goes green. :ScryRatify puts your name on it.
Foresight is now fact, and someone vouches for it.

The seal

the one thing in the glass that is warm
lua/auth.lua:create_session -- @w0zro 2026-07-26 6b8f0e
Your name, the date, six hex of sha256 of the claim's own text. Edit the claim and the seal breaks — the hash stops matching, the ∅ unsigned mark returns. No hooks, no hidden state, visible in git diff. Signing is cheap to do and impossible to fake having done: you can't put your name on a sentence you haven't read.

Five commands

zero config works · :h scry is the manual
CommandDoes
:ScryOpen the glass; check every claim.
:ScryCheckRe-check against the files on disk.
:ScryCascadeConjure the absent claim under the cursor, prohibitions withheld.
:ScryRunRun the specs behind exercises claims, then re-check. The only command that executes your code.
:ScryRatifySign the claim under the cursor.

require("scry").setup({
  map_path = ".scry/map.scry",
  holdout_path = "",   -- "" = outside the repo
  author = "",         -- "" = git user.name
  resolver = "",       -- "" = treesitter + rg
  test = { cmd = {} },  -- one spec; path appended
})

The glass doesn't flatter

its limits, stated as plainly as its verdicts
You write the map. Nothing is recovered from the code — recovered models are half right, which is worse than absent.
Backed is not correct. claimed → backed → exercised. Nothing here says your code is right.
contains ✓ — a definition with that name exists. Nothing about its body.
calls ✓ — the token occurs and the target exists. Not a resolved call.
never ✓ — no textual match. local ui = vim.ui defeats it.
exercises ✓ — a process exited 0, at a stated age. Not proof a feature works.
Verdicts describe saved files. Unwritten buffers are invisible; the timestamp travels with the render.
Withholding guards against leakage, not adversaries. A spec must live in the tree to run, so hiding it is request-level only.
The cascade seeds the file's first line. scry knows which file, not where in it. Placement is the model's call; review is yours.
Seals are records, not identity. @name is your git config.
Name what isn't. Then make it so.
